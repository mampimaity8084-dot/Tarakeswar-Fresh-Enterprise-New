DELIVERY PARTNERS
-----------------
Admin -> Delivery Partners:
1. Enter Rahul + email + mobile + vehicle -> Create/Update.
2. Repeat for Suman, Arindam, etc.
3. Generate QR Login for each partner.
4. Print/save the QR and give it to that partner.
5. Partner scans QR on their phone.
6. The secure Supabase magic link opens delivery.html and establishes the login session.
7. Install the Delivery PWA from Chrome menu / Install button.

The QR does NOT contain a password.

ORDER ASSIGNMENT
----------------
Admin -> Orders -> choose a Delivery Partner from the assignment dropdown.
Only the assigned partner's delivery queue is shown in the Delivery App.

GPS
---
Delivery partner must:
- allow Location permission
- keep phone Location/GPS ON
- use HTTPS Netlify URL
- press Start Live GPS after an Out for Delivery order is assigned.

The dashboard updates order/location data and uses Supabase Realtime where enabled.

PUSH NOTIFICATIONS
------------------
Customer opens the app -> taps the bell -> Allow notifications.

The notification backend uses VAPID keys.

PERFORMANCE
-----------
Static app shell is cached by service workers.
Admin and Delivery dashboards use Realtime plus fallback refresh.
Delivery fallback refresh is 30 seconds.
Actual first-load time depends on device/network/Supabase response; 1-2 seconds is a target, not a guaranteed SLA.
