# V4.3 Deployment Guide

Deployment is intentionally blocked for this candidate.

Before any future deployment:

1. Review the payment flow and database migration plan.
2. Run migrations only against a disposable/non-production Supabase project.
3. Configure Razorpay sandbox credentials only in the isolated environment.
4. Run the full acceptance checklist.
5. Verify the deploy tree before changing `netlify.toml`.
6. Produce a release diff against V4.2.
7. Obtain explicit production approval.

Never deploy this candidate directly to the production Netlify site.
